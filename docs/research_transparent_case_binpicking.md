# 투명 사각형 화장품 케이스 빈피킹 — 비전 기술 조사 보고서

- **작성일**: 2026-07-10
- **목적**: 아이섀도우 화장품 케이스(투명 플라스틱, 사각형, 다품종 소량생산, CAD 없음) 빈피킹 솔루션 개발을 위한 기술 조사
- **전제 시스템**: KUKA 로봇 + RealSense D415 (액티브 스테레오 RGB-D), Python, Grounding DINO(제로샷 검출) + SAM 조합으로 케이스 검출까지 검증 완료
- **핵심 문제**: 케이스가 투명이라 D415 깊이 측정 실패 → 현재는 "높이 고정 가정"으로 우회 중

> **검증 상태**: 조사는 다중 소스 자동 수집 + 핵심 주장 직접 재검증으로 수행. ✅ 표시 = 1차 소스(arXiv 초록/GitHub README)로 직접 확인한 주장. 표시 없는 항목은 1차 소스 발췌 기반으로, 도입 전 추가 확인 권장.

---

## 요약 (결론 먼저)

1. **위치+회전**: 보유한 GDINO+SAM 마스크에 `cv2.minAreaRect` 한 줄이면 위치+평면 회전각이 나온다 — 즉시 구현 가능. 완전한 6D가 필요하면 **Any6D**(참조 사진 1장) 또는 **Box6D**(박스 카테고리 특화)가 CAD 없는 조건에 부합.
2. **열리는 방향**: "축"은 minAreaRect가 주므로 문제는 **180° 이진 판별로 축소**된다. 힌지 이음선 등 외관 단서 기반 고전 CV + VLM 4지선다 폴백이 실용적. 범용 VLM의 공간 추론 신뢰도가 낮다는 벤치마크가 있어 **구속된 질문으로 단순화**가 핵심.
3. **투명체 높이**: 2024~2025년에 D415급 카메라용 투명체 깊이 복원이 크게 발전. **ASGrasp**(D415급 액티브 스테레오 전용, 체크포인트 공개)와 **TransCG/DFNet**이 바로 시도 가능한 1순위. "높이 고정 가정"도 산업 현장에선 합리적 폴백.

## Q1. 훈련 없이 위치 + 회전 구하기

### 1-A. 지금 바로: SAM 마스크 → 회전 사각형 (추천 1단계)

SAM 마스크에서 `cv2.findContours` → `cv2.minAreaRect` 를 돌리면 **중심(x,y) + 평면 회전각 + 가로세로 크기**가 즉시 나온다. 케이스가 빈에 눕혀져 있고(윗면이 카메라를 향함) 사각형이라는 조건에서는 6D 중 실질적으로 필요한 자유도(x, y, 평면 회전 — z는 Q3)가 이걸로 해결된다.

- 훈련: 불필요 / 실시간: ✅ (μs 단위) / 난이도: 매우 낮음 / 오픈소스: OpenCV 표준

### 1-B. 완전한 6D가 필요할 때 — zero-shot 6D pose 모델 비교

| 모델 | CAD 필요? | 사전 준비 | 비고 |
|------|-----------|----------|------|
| **Any6D** ✅ ([arXiv 2503.18673](https://arxiv.org/abs/2503.18673)) | ❌ | **RGB-D 앵커 사진 1장** | "단일 RGB-D 앵커 이미지만으로 미지 객체의 6D pose와 **크기**를 추정" (초록 원문 확인). 신제품마다 사진 1장이면 됨 — 다품종 소량에 최적 |
| **Box6D** ✅ ([arXiv 2511.15884](https://arxiv.org/abs/2511.15884)) | 카테고리 템플릿만 | 없음 | "인스턴스 CAD 대신 **카테고리 CAD 템플릿**으로 단일 RGB-D에서 박스 치수+6D 추정, 추론시간 ~76% 단축" 확인. **사각 박스류 전용 — 본 과제와 정확히 일치** (2025.11) |
| FoundationPose ([GitHub](https://github.com/NVlabs/FoundationPose)) | CAD 또는 참조 이미지 | model-free 모드는 참조 뷰들로 Neural Object Field 재구성 필요 | 검증된 SOTA지만 케이스마다 온보딩 단계가 있어 "어떤 게 나올지 모르는" 조건에 부담 |
| HIPPo ([arXiv 2502.10606](https://arxiv.org/html/2502.10606v1), 발췌 기반) | ❌ | 없음 (첫 관측에서 메시 생성 ~8초, 이후 ~15FPS) | Grounding DINO 기반이라 파이프라인 결이 같음. 미검증 — 추가 확인 권장 |
| FreeZe / Geo6DPose | ⭕ CAD 필수 | — | **부적합** (CAD 없음) |

⚠️ **공통 함정**: 이 모델들 대부분 **깊이 입력이 필요**하다. 투명 케이스에서 D415 깊이가 깨지면 6D 모델 입력부터 오염되므로 **Q3(깊이 복원)가 선행**되어야 한다.

## Q2. 열리는 방향(힌지/뚜껑) 인식

핵심 통찰: minAreaRect가 장축 방향을 주므로, 남는 문제는 **"힌지가 두 변 중 어느 쪽인가" = 180° 이진 분류**뿐이다.

### ① 외관 단서 기반 고전 CV (훈련 무관, 추천 1순위)

- 힌지 쪽: 이음선/금속 핀이 보이는 어두운 띠, 뚜껑-바닥 이중 윤곽
- 여는 쪽: 손톱 노치(오목 홈), 걸쇠 버튼
- 케이스가 **투명해서 내부가 보이는 걸 역이용**: 아이섀도 팬·거울·브러시 홈 배치는 힌지 기준으로 비대칭 → 마스크 내부 색 분포의 비대칭으로 판별 가능
- 회전각으로 크롭을 정규화(케이스를 항상 똑바로 세운 이미지)한 뒤 두 변의 에지 밀도/색 히스토그램 비교 — 구현 반나절 수준

### ② Orient Anything ✅ ([arXiv 2412.18605](https://arxiv.org/abs/2412.18605))

단일 RGB에서 객체의 "정면 방향" 3각도(방위각/극각/회전)를 zero-shot 추정하는 전용 모델. 초록에서 실사 이미지 zero-shot SOTA 확인, 코드 공개. 단, 거의 대칭인 케이스에서 "정면"의 의미가 약할 수 있어 실측 평가 필요.

### ③ VLM(GPT-4V/Gemini/Claude) 질의

회전 정규화된 크롭을 주고 "힌지가 상/하/좌/우 어느 변인가?" 4지선다. 훈련 불필요·구현 최소. 주의: **ViewSpatial-Bench**([arXiv 2505.21500](https://arxiv.org/abs/2505.21500))에 따르면 범용 VLM의 시점·방향 공간 추론은 약하다고 보고됨(초록 수준 확인; 세부 수치 — GPT-4o 전체 ~35%, 방향 과제 ~20% — 는 발췌 기반). 다만 이는 자유 시점 벤치마크이고 **정규화 크롭 + 구속된 4지선다**는 훨씬 쉬운 문제이므로, 실제 케이스 20장 규모의 자체 평가로 판단 권장. 사이클당 API 지연(~1초)도 고려.

### 실무 추천

①로 시작 → 애매한 케이스만 ③으로 폴백하는 2단 구조. 신뢰도가 계속 낮으면 소량 라벨링(케이스당 사진 몇 장)으로 경량 이진 분류기를 파인튜닝하는 것이 현실적 탈출구 (훈련 제로는 아니지만 라벨 부담이 매우 작음).

## Q3. 투명 케이스의 높이/깊이 측정

**왜 D415가 실패하나**: D415의 IR 패턴이 투명면에서 투과·굴절되어 해당 영역 깊이가 구멍(NaN)이 되거나 **뒤쪽 배경의 깊이**가 찍힌다 ([투명체 인식 리뷰, arXiv 2304.00157](https://arxiv.org/pdf/2304.00157)).

### 소프트웨어 접근 (D415 유지 — 추가 하드웨어 없음)

| 방법 | 훈련 | 실시간성 | 난이도 | 코드 | 비고 |
|------|------|---------|--------|------|------|
| **ASGrasp** ✅ ([GitHub](https://github.com/jun7-shi/ASGrasp), ICRA 2024) | 불필요 (체크포인트 공개) | GPU 실시간급 | 중 | ✅ | **액티브 스테레오(D415급) 전용 설계** — RGB+IR 원시 영상으로 투명체 3D 복원 + 6DoF 파지까지. D415 좌/우 IR 스트림 접근 필요 (pyrealsense2로 가능) |
| **TransCG + DFNet** ([GitHub](https://github.com/Galaxies99/TransCG)) | 불필요 (체크포인트 공개) | 실시간급 (경량) | 낮음 | ✅ | 실측 5.7만 장 데이터셋의 표준 베이스라인. RGB-D → 투명 영역 깊이 복원. **가장 빨리 붙여볼 수 있는 선택지** |
| **ReMake** ✅ ([arXiv 2508.02507](https://arxiv.org/abs/2508.02507), 2025) | 불필요 (코드 공개) | 확인 필요 | 중 | ✅ | **단안 깊이 추정 + 인스턴스 마스크**로 투명 영역만 골라 복원 — **GDINO+SAM 마스크와 구조적으로 궁합 최고** |
| HDCNet ([arXiv 2511.07081](https://arxiv.org/pdf/2511.07081)) / DCIRNet ([arXiv 2506.09491](https://arxiv.org/pdf/2506.09491)) | — | — | — | 확인 필요 | 2025년 최신 depth completion 계열 (미검증, 벤치마크 우위 주장) |
| D3RoMa ([arXiv 2409.14365](https://arxiv.org/pdf/2409.14365)) | 불필요 | diffusion이라 느린 편 | 중상 | ✅ | 스테레오 IR 쌍에 diffusion — 재질 불문 깊이. 정밀도 우선일 때 |
| Depth Anything v2 (단안) | 불필요 | 실시간급 | 낮음 | ✅ | 투명면에 상대적으로 강건하지만 **상대 깊이** → 주변 바닥/불투명 영역의 D415 깊이로 스케일 앵커링하는 하이브리드가 실용적 |
| ClearGrasp (2020) | 불필요 | 느림 | 중 | ✅ | 이 분야의 원조. 현재는 후속 방법들이 우월 — 참고용 |

### 실용 트릭 (모델 없이, 즉시 가능)

1. **"깊이 구멍 = 투명체" 역발상**: SAM 마스크 영역의 D415 깊이가 NaN/배경값인 것 자체가 투명체 존재 증거. **주변 바닥(빈 바닥) 깊이 − 알려진 케이스 높이 = 윗면 깊이** — 현재 쓰는 높이 고정 가정의 정식화이며 단층 배치에선 충분히 견고.
2. **내용물 깊이 활용**: 아이섀도 팬(불투명)은 투명 뚜껑 너머로 IR이 일부 잡힘. 단, 뚜껑 굴절로 실제보다 몇 mm 깊게 측정되는 바이어스 주의.
3. 하드웨어 대안(참고): 편광 카메라, 라인 레이저 프로파일러 — 확실하지만 비용/통합 부담. 소프트웨어 복원을 먼저 시도할 가치가 있음.

## 최종 추천 파이프라인

```
[보유] Grounding DINO + SAM ──→ 마스크
   ├─ ① cv2.minAreaRect → 위치 + 평면 회전각          (즉시)
   ├─ ② 깊이: 1단계 = 바닥깊이 − 알려진 높이 (현행 정식화)
   │         2단계 = TransCG/DFNet 또는 ASGrasp 로 복원 깊이 교체
   │         (ReMake 방식처럼 SAM 마스크로 투명 영역만 타겟팅)
   └─ ③ 방향: 회전 정규화 크롭 → 힌지 단서 CV 판별
              → 애매하면 VLM 4지선다 폴백
```

- **1주차**: ① + ②1단계 + ③CV — 전부 훈련·신규 모델 없이 동작하는 MVP
- **2주차**: DFNet 체크포인트로 깊이 복원 A/B 테스트 (D415 실측으로 복원 오차 확인)
- **필요시**: 6D가 정말 필요해지면 Any6D(제품별 사진 1장) 또는 Box6D 평가
